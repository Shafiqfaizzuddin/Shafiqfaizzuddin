## 🚀 Featured Projects

### ♻️ AI-Powered Waste Management & Reporting System

**Final Year Project · In Development**

`React` · `FastAPI` · `Python` · `Ollama` · `Vision-Language Models` · `Supabase`

A web-based system exploring how **AI-assisted image understanding** can support more efficient waste reporting and management. Designed with campus waste reporting in mind, the project brings together a responsive web interface, backend services, and multimodal AI capabilities.

<details>
<summary><strong>🔎 Project scope & technical focus</strong></summary>

- AI-assisted analysis of waste images using vision-language models.
- Structured reporting workflows and backend APIs.
- Cloud-backed storage and data management with Supabase.
- Exploration of report verification, recycling support, and student engagement features.
- Evaluation of model behaviour and practical performance as development progresses.

> This is an ongoing final-year project. Items above describe the intended scope and areas of development, not a claim that every feature is complete.

</details>

### 💼 NiagaPilot — AI-Assisted Financial Workspace

**Independent Project · In Development**

`React` · `Vite` · `Firebase` · `NVIDIA Nemotron`

A **mobile-friendly financial workspace for Malaysian microbusiness owners**, designed to make basic financial tasks and information more approachable for people without a formal accounting background.

<details>
<summary><strong>🔎 Project scope & technical focus</strong></summary>

- Accessible, mobile-first web experience for small business owners.
- AI-assisted explanations of financial concepts and workflows using NVIDIA Nemotron.
- Firebase-backed application services and data management.
- Emphasis on understandable interfaces, practical workflows, and responsible AI guidance.

> NiagaPilot is under active development. Feature descriptions reflect the project's goals and technical direction.

</details>
